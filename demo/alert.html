Alert

A tinted, bordered message block. .alert is a flex row with gap-3, so it lays out an optional leading .icon against one or more content children.

Variants

Heads up — this is an info alert.
Nice — this is a success alert.
Careful — this is a warning alert.
Uh oh — this is a danger alert.

.alert-info is the only variant tinted from the brand ramp rather than a semantic hue — which is why it doubles as this demo's "note" callout.

Without an icon

No component in this system requires an icon to render correctly, and the package ships no icon set at all. An alert with nothing but text is a first-class case, not a degraded one.

Accessibility

.alert is purely presentational — it sets no ARIA role, because whether a message should interrupt a screen reader depends on why it appeared. Add role="status" for informational and success messages, and role="alert" for warnings and errors that need immediate attention.
