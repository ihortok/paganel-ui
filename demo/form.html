Form controls

.input, .textarea and .select are one shared rule, so the three line up by default. There is no .form container class — form layout is .field for each control plus ordinary layout utilities around them.

Error states

The -error modifiers only recolor the border and focus ring. They don't announce anything, so you still set aria-invalid="true" and point aria-describedby at the message.

Not covered yet: radios

Classes

.field
Flex column with gap-1.5 — wraps one control with its label, hint and error.
.label
Small medium-weight label text.
.input / .textarea / .select
One shared rule: border, radius, padding, focus ring, disabled state. .textarea adds a minimum height and vertical resize.
.input-error / .textarea-error / .select-error
Modifiers — combine with the base class. Recolor border and focus ring only.
.checkbox
Sized box with a brand accent color and a focus ring.
.checkbox-label
The row around a checkbox and its text, aligned with gap-2.
.hint
Small muted helper text.
.error-message
Small danger-colored validation text.
