Icons

Paganel UI ships no icon set and has no icon dependency. .icon is a neutral fixed-size slot — combine it in markup with whatever your app uses. Both rows below share one box, so they align in a column regardless of origin; an icon font's <i> slots into the same class identically.

One box, many sources

The outline below is the .icon box itself, made visible. Left alone these four would size themselves by completely different rules — an icon font sizes in em, a bare inline <svg> has no usable intrinsic size, a glyph is whatever the font gives. The shared box is the whole point.

Details worth knowing

.icon is inline-block, not inline-flex. Icon-font CSS is typically unlayered, and unlayered rules beat @layer ones — matching the display: inline-block such sets already use avoids a cascade fight this would lose. Centring comes from text-center plus the matching line-height instead.

Icons here are decorative, so they carry aria-hidden="true" and the label beside them does the talking. When an icon is the only content — an icon-only button — put an aria-label on the control.

shrink-0 is part of the base, so an icon never gets squeezed when its flex container runs out of room.

Classes

.icon
The slot: 20×20, inline-block, shrink-0, centred, with a matching line-height.
.icon-sm
Modifier — 16×16. Combine: class="icon icon-sm".
