Dropdown

Three classes and three data attributes. The behavior ships with the package and initializes itself on import — there is no per-instance setup call.

Basic

Right-aligned

.dropdown-menu is absolutely positioned against .dropdown, and defaults to the left edge. Add the right-0 utility when the trigger sits near the right of the viewport — this is what the avatar menu in the header uses.

Links as items

.dropdown-item is element-agnostic — use <a> when the item navigates and <button> when it acts. These really navigate.

Behavior

A dropdown opens on trigger click and closes on any of: clicking the trigger again, clicking outside the panel, pressing Escape (which returns focus to the trigger), or clicking anything marked data-ds-dismiss="dropdown" inside the panel.

The required wiring is three attributes plus a matching id:

  • trigger — data-ds-toggle="dropdown", aria-controls pointing at the panel's id, and aria-expanded="false"
  • panel — data-ds-panel="dropdown" and the hidden attribute
  • items that should close the menu — data-ds-dismiss="dropdown"

All state lives in DOM attributes (aria-expanded, hidden) rather than in a JS-side instance map. That is what makes it safe under Turbo Drive: markup swapped in after a navigation is indistinguishable from markup that was there on load, so there is no instance to lose and no re-init hook to call.

One delegated listener set is installed on document for the whole page, no matter how many dropdowns exist.

Ids must be unique per page

Panels are resolved through getElementById and [aria-controls], so a duplicated id silently wires a trigger to the wrong panel. The shared header on every page of this demo already uses user-menu — which is why the four menus above are dropdown-basic, dropdown-right, dropdown-links and dropdown-groups. Open the avatar menu in the header and one of these together to confirm they stay independent.

Classes

.dropdown
Positioning context — relative inline-block around trigger and panel.
.dropdown-menu
The floating panel. Sets no display utility on purpose: visibility is the native hidden attribute alone, so nothing fights it at equal specificity.
.dropdown-item
Full-width row, flex so an .icon gets gap-2 spacing, with a hover background.
