Paganel UI

A small design system built on Tailwind CSS v4: component classes authored with @apply, plus vanilla-JS behaviors driven entirely by HTML data-* attributes. This demo is a plain static site — one page per component, real links, full page loads, no framework. Every example is markup you can view-source and paste.

The chrome is a component too

The bar at the top is .header; the column on the left is .sidebar. Below the lg breakpoint the sidebar becomes .sidebar-drawer — narrow the window and use the round toggle in the bottom-right corner. Both are fixed, so page content sits in <div class="pt-16 lg:ml-60"> to clear them.

Design tokens

Color ramps, radii, shadows and the serif face, as @theme variables.

Icons

One fixed-size slot for any icon source. No icon set ships with the package.

Card

Surface with optional header, body, footer, and bleeding media.

Button

Three variants × three sizes, composed in markup rather than nested in CSS.

Badge

Small uppercase status label in four semantic colors.

Alert

Tinted message block, with an icon or without one.

Dropdown

JS

Menu with outside-click and Escape handling, wired by data attributes.

Form controls

Fields, labels, inputs, selects, checkboxes, hints and error states.

Avatar

Circular image that crops any aspect ratio to the same shape.
