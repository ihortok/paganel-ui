Avatar

One class doing one job: a fixed-size circle that crops whatever image you give it. It's block, so inside a row it's the parent that aligns it.

Default

Any aspect ratio, one circle

This is what object-cover is in the class for. Three source images — square, landscape and portrait 2:3 — with no per-image handling. Uploaded avatars are never the shape you hoped for.

Sizes

No .avatar-sm / .avatar-lg ships. Utilities sit above @layer components in the cascade, so a plain size-* utility overrides the default without needing a modifier class.
